## ארכיטקטורה
- Next.js App Router + TypeScript + Tailwind, פריסה ל-Vercel. עמודים סטטיים.
- `content/site.ts` – מקור אמת יחיד לשירותים, פרויקטים ופרטי קשר. מזין עמודים, sitemap והצ'אט.
- `/api/chat` – OpenAI streaming. System prompt נבנה מקובץ התוכן; עונה רק על שירותים, פרויקטים, יצירת קשר. הגבלת קצב בסיסית לפי IP (בזיכרון; מספיק לאתר תדמית). הגבלת אורך הודעות והיסטוריה.
- `/api/contact` – ולידציה בצד שרת + honeypot, שליחה דרך Resend.
- Env: `OPENAI_API_KEY`, `RESEND_API_KEY`, `NEXT_PUBLIC_SITE_URL`.
